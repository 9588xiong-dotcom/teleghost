# TeleGhost product steering

- Category: Resurrection. Reimagine obsolete Teletext as a useful, lightweight modern information service.
- Preserve recognizable Teletext concepts: numbered pages, color-coded categories, keyboard navigation and compact content.
- Make the project genuinely useful with current information sources, rather than relying on nostalgia alone.
- Prefer simple, maintainable and well-tested code. Avoid unnecessary dependencies and authentication.
- Show content source, last-updated time, loading/error states and honest demo-data labels.
- Preserve keyboard access, readable contrast, visible focus and reduced-motion behavior.
- Never describe work as completed in Kiro unless it actually was performed in Kiro.
